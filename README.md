# Connecso for Windows

Connecso is a Windows client for Xray-compatible proxy subscriptions. This repository's latest Windows release is **0.2.2 (prerelease)**.

[Download Connecso 0.2.2](https://github.com/SocalledTaha/Connecso/releases/tag/v0.2.2)

## Downloads

- **Portable:** [Connecso-0.2.2-Portable-Windows-x64.zip](https://github.com/SocalledTaha/Connecso/releases/download/v0.2.2/Connecso-0.2.2-Portable-Windows-x64.zip)
- **Installer:** [Connecso-0.2.2-Windows-x64-Setup.exe](https://github.com/SocalledTaha/Connecso/releases/download/v0.2.2/Connecso-0.2.2-Windows-x64-Setup.exe)

## Features

- Xray-compatible connection profiles and subscriptions
- Split tunneling with per-application Proxy and Bypass policies
- Telegram Proxy and Windows System Proxy controls
- Performance Mode
- Minimize to Tray and tray controls
- Light and dark themes

The Windows packages include the native routing helper and WFP driver used by per-application split tunneling.

## Install

Choose either the portable ZIP or the setup installer from the release page. For the portable version, extract the ZIP and launch `connecso_client.exe`. For the installer, run the setup file and follow its prompts.
